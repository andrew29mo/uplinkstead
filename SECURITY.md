# Security

Uplinkstead is an experimental single-node IPv4 failover service, not a production
qualification. Only the current main branch is maintained. Review the operational
prerequisites and limits in [README](README.md) before deployment.

Please report vulnerabilities using GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/andrew29mo/uplinkstead/security/advisories/new).
Do not publish credentials or exploitable details in a public issue. No response
or remediation time is guaranteed.
